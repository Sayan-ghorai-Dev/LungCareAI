# LungCare AI

Educational machine-learning project for analyzing a lung-cancer survey dataset.

## Setup

1. Open this folder in VS Code.
2. Create and activate a Python virtual environment.
3. Install dependencies: `python -m pip install -r requirements.txt`
4. Place the genuine Kaggle CSV at `data/lung_cancer.csv`.
5. The training pipeline and Streamlit pages will be implemented step by step.

**Disclaimer:** This project is for academic learning only. It must not be used to diagnose, screen, or guide medical decisions. Model metrics on survey data do not establish clinical performance.
